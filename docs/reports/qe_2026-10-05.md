## Findings

| # | Severity | Finding | Status |
|---|---|---|---|
| 1 | Low | When the scheduler stopped, `worker` also showed stale: the worker heartbeat was written only by the scheduler-enqueued job, so the two failures could not be told apart | **Fixed in M0.3.** The worker writes its own heartbeat from a background thread; a separate `queue` heartbeat proves the scheduler → queue → worker path. Re-tested: with the scheduler stopped, worker = ok, scheduler = stale, queue = stale |
| 2 | Low (local only) | Default credentials for Postgres (`app/app`) and the object store (`minioadmin`); Redis has no password | Accepted while every port binds to 127.0.0.1 (errata E12). Must change before any non-local deployment (OD-8) |
| 3 | Low | `license_status` values in M0.2 did not match the glossary term | **Fixed in M0.3** (migration 0002, plan D1); a test now compares code with the glossary |
| 4 | Low | M0.2 audit trigger wrote a row for UPDATEs that changed nothing (the M0.2 plan said it would not) | **Fixed in M0.3** (migration 0002 replaces `audit_row_change()`) |
| 5 | Info | A test probing `audit_log` UPDATE/DELETE on an empty table passes vacuously (row triggers do not fire on zero rows) | Re-tested with a row present: refused. Tests always create a row first |
